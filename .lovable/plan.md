# تطوير بطاقة "اقتراحات الإقفال الذكية" — Noir Commander

اعتمدنا الاتجاه المختار: بطاقة قيادية داكنة بحواف ذهبية، ثلاث بلاطات إحصائية مضاءة، وزر إجراء رئيسي ذهبي — مع الحفاظ على كل الوظائف الحالية (النقر لفتح الفواتير، شرح "لماذا؟"، الحالات الفارغة، التحميل).

## الملف المعدَّل
- `src/components/closeable-invoices-card.tsx` — إعادة بناء الواجهة فقط، دون تغيير أي منطق أو استعلامات أو RPCs.

## عناصر التصميم المُطبَّقة (مطابقة للنموذج)
1. **الحاوية**: خلفية متدرّجة `from-[#161616] to-[#0d0d0d]`، حدود ذهبية شفافة `border-[#c9a84c]/20`، ظل عميق، شريط علوي ذهبي متدرّج، وهج ذهبي خفيف أسفل البطاقة.
2. **رأس البطاقة**: أيقونة ذهبية داخل مربع مضاء + عنوان "اقتراحات الإقفال الذكية" + عنوان فرعي وصفي، مع زر "لماذا؟" بحدود ذهبية على اليسار (بديل الـ Popover الحالي).
3. **البلاطات الثلاث** (جاهزة الآن / بعد الوصول / محجوزة):
   - كل بلاطة `rounded-2xl` بخلفية `#1a1a1a` وحدود شفافة تتلوّن عند الـ hover بلون الحالة.
   - أيقونة دائرية ملوّنة (أخضر/أزرق/كهرماني) + رقم كبير بلون الحالة.
   - وهج خلفي blur يتضخّم عند الـ hover.
   - تبقى قابلة للنقر لفتح قائمة الفواتير المفلترة (نفس السلوك الحالي).
4. **زر الإجراء الرئيسي**: زر ذهبي عريض أسفل البطاقة "عرض الاقتراحات الذكية" مع سهم — يفتح تبويب "جاهزة الآن" افتراضيًا (سلوك جديد بسيط، بدون منطق backend).
5. **الحالات**: Skeleton داكن متناسق أثناء التحميل، ورسالة فارغة أنيقة عند غياب الاقتراحات.

## قواعد الالتزام
- بدون ألوان hardcoded خارج بالتة Noir & Gold المعتمدة (أسود/ذهبي/رمادي + دلالات green/blue/amber للحالات فقط، مطابقة للنموذج).
- RTL كامل، خط Open Sans، بدون تغيير في hierarchy الصفحة الأم.
- بدون تعديل على `src/routes/dashboard.tsx` أو أي منطق حسابي.

## التحقق
- فتح `/dashboard` والتأكد من: ظهور الأرقام الصحيحة، النقر على كل بلاطة يفتح الفواتير المطابقة، زر "لماذا؟" يعرض الشرح، الاستجابة على شاشات الموبايل (البلاطات تتحوّل إلى صف واحد قابل للتمرير أو grid مضغوط).
