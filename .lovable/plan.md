## الهدف
إضافة تصدير Excel للفواتير (غير الملغية/المحذوفة) بنفس شكل ملف Ceramica_Market_Orders، مع إمكانية اختيار فاتورة واحدة أو أكثر.

## التغييرات

### 1. صفحة الفواتير `src/routes/invoices.index.tsx`
- إضافة عمود checkbox في بداية كل صف + checkbox "تحديد الكل" في الهيدر.
- شريط أدوات يظهر عند تحديد فاتورة أو أكثر، فيه:
  - عدد الفواتير المختارة
  - زر **"تصدير Excel (نمط الطلبات)"**
  - زر "إلغاء التحديد"
- استبعاد الفواتير `status = voided` من قابلية التحديد.

### 2. منطق التصدير `src/lib/orders-export.ts` (ملف جديد)
- يستقبل قائمة `invoiceIds` ثم يجلب من قاعدة البيانات:
  - `invoices` (رقم الفاتورة، اسم العميل)
  - `invoice_items` (serial_number, product_name, color, quantity)
- يبني ملف Excel واحد بشيتين:

**شيت 1: `Orders`** — كل الفواتير تحت بعض بنفس شكل العينة:
| العمود | المحتوى |
|---|---|
| A | Inv # (رقم الفاتورة، يظهر مرة واحدة في أول صف لكل فاتورة) |
| B | invoice Name (اسم العميل، مرة واحدة في أول صف) |
| C | Code (السيريال نمبر) |
| D | Name (اسم المنتج + اللون) |
| E | Quantity |

- صف عنوان "Ordered items" أعلى الجدول كما في العينة.
- **تجميع داخل الفاتورة**: لو نفس (serial + product + color) متكرر داخل فاتورة، يُدمج في صف واحد بإجمالي الكمية.
- صف فاصل فارغ بين كل فاتورة والتي تليها.
- صف **"Invoice Total"** في نهاية كل فاتورة بإجمالي الكميات.

**شيت 2: `Summary`** — تجميع عبر كل الفواتير المختارة:
| Code | Name | Total Quantity | Invoices Count |
|---|---|---|---|
- مرتب تنازلياً حسب الكمية الإجمالية.
- صف TOTAL في الأخير.

### 3. تنسيق
- خط Arial، رؤوس بخلفية خفيفة وعريضة.
- عرض أعمدة مناسب (Code ~22، Name ~40، Quantity ~12).
- اسم الملف: `orders_<YYYY-MM-DD>_<count>invoices.xlsx`.

## ملاحظات تقنية
- استخدام مكتبة `xlsx` المتوفرة بالفعل في المشروع.
- الاستعلام يتم في الـ client عبر `supabase` client مع RLS الحالي.
- التحديد محفوظ في `useState` داخل صفحة الفواتير فقط (يتمسح عند تغيير الفلاتر).
