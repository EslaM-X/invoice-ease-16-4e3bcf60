## المشكلة

في جدول «ربح كل منتج» عمود **سعر التكلفة** بيعرض `product.cost_price` (التكلفة الحالية الخام للمنتج فقط) — بينما عمود **إجمالي التكلفة** بيتحسب بـ `costOf()` اللي بيحترم مصدر التكلفة المختار (WAC / Latest PO / Current / Override) + الأوفررايد اليدوي.

النتيجة: لو `cost_price` = 0 لكن فيه WAC أو أوفررايد، بيظهر «EGP 0.00» في عمود سعر التكلفة، بينما إجمالي التكلفة بيبان كبير — تناقض بصري صريح زي اللي في السكرين.

نفس البق موجود في قسم «معادلة الحساب» داخل صف التوسعة (بيستخدم `p.cost_price` بدل الوحدة الفعلية).

## الإصلاح (frontend فقط، `src/routes/profits.tsx`)

1. **حساب وحدة التكلفة الفعلية لكل صف**
   - في `rows` map، أضيف حقلين مشتقين:
     - `unitCost` = `r.qty > 0 ? r.cost / r.qty : costOf(pid)` (متوسط الوحدة الفعلي = إجمالي التكلفة ÷ الكمية)
     - `costSourceUsed` = نوع المصدر المطبَّق (`override` / `wac` / `latest_po` / `current`) — يتحدد بنفس منطق `costOf`.

2. **عمود «سعر التكلفة»**
   - عند عدم التعديل، اعرض `fmtMoney(r.unitCost)` بدل `p.cost_price`.
   - أضف Tooltip (shadcn `<Tooltip>`) يوضح المصدر بالعربي/الإنجليزي:
     - «متوسط مرجّح (WAC)» / «آخر أمر شراء» / «التكلفة الحالية» / «تعديل يدوي».
   - Badge صغير جوّه الخلية (`text-[9px]` ذهبي خفيف) يعرض اختصار المصدر: `WAC` / `LPO` / `CUR` / `MAN`.

3. **تمييز بصري للـ «صفر حقيقي»**
   - لو `r.unitCost === 0` **و** `r.qty > 0`:
     - إطار ذهبي رفيع حول الخلية (`ring-1 ring-amber-500/40`) + أيقونة تحذير (`AlertTriangle` من lucide) بلون ذهبي.
     - Tooltip: «لا توجد بيانات تكلفة لهذا المنتج — الربح مبالغ فيه» / "No cost data — profit is overstated".
   - لو `r.unitCost === 0` **و** `r.qty === 0` (منتج بدون مبيعات): اعرض `—` رمادي بدون تحذير.

4. **صف الصفوف السالبة → تحذير أقوى**
   - لو المنتج فيه تحذير الصفر، ضيف شريط ذهبي رفيع يسار الصف (`border-s-2 border-amber-500/60`) عشان يبان في الجدول من غير scroll.

5. **قسم «معادلة الحساب» (Expanded row)**
   - استبدل كل ظهور لـ `p.cost_price` بـ `r.unitCost`.
   - أضف سطر «مصدر التكلفة» يعرض `costSourceUsed` بشكل صريح.
   - لو تحذير الصفر مفعّل، أضف بلوك ذهبي صغير: «⚠ لا يوجد سعر تكلفة مسجّل — الرقم صفر».

6. **تصدير Excel**
   - عمود «سعر التكلفة» في الشيت يستخدم `r.unitCost` بدل `p.cost_price` عشان يطابق الجدول.
   - عمود جديد «مصدر التكلفة» بعده.

## Out of scope (مش هنعمله دلوقتي)

- تغيير منطق حساب `r.cost` نفسه (شغال صح بالفعل).
- تعديل جدول `products` أو أي RPC.
- إشعارات global (فيه ريبون Reconciliation موجود بالفعل).

## المحصلة

المستخدم يبقى شايف نفس القيمة اللي بتتضرب في الكمية = إجمالي التكلفة (اتساق حسابي)، وأي منتج تكلفته صفر فعلاً بيبان بتحذير ذهبي واضح فوراً بدل ما يفتكر إن فيه bug.
